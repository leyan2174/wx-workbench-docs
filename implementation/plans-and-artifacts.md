# 不可变计划与受控产物

证据：C；固定提交 `b7015ad2b7060a5dff6ddb9a9e2cc3a88403e86e`。依据 `src/service/chat_plan.rs`、`src/service/task_artifacts.rs`、`src/daemon/operations/plan_tasks.rs` 与 `src/daemon/tasks/` 的计划、登记及文件读取实现，并对照同版本 `docs/task-artifacts.md`。本章说明实现边界，不提供真实账号测试结论。

## 计划引用与选集

任务类型 `chat_plan` 生成计划，`chat_plan_review` 发布修订，`chat_plan_apply` 执行选集。它们复用任务队列、幂等与取消流程；前台 `wx chats plan` 的显式离线 CSV 路径有独立生命周期，不能把两种入口视为相同授权。

计划任务返回的 `published_plan_ref` 包含 `task_id`、`artifact_id`、`sha256`。后续请求原样携带引用，不提交 CSV 文件路径；daemon 验证账号、配置、发布身份及摘要。只读计划页返回类型化行，不能把显示名称或行号用作文件路径。

- 省略 `users` 表示会话摘要目录中的全部会话；显式空数组表示空选集。使用稳定 username，未知身份拒绝、重复身份去重。只有消息表而没有会话摘要的身份不属于该入口的计划目录。
- `size_mode=estimate` 估计体积；`scan` 扫描本地媒体目录，不是内存取钥。MCP/Web 新提交的 scan 需要宿主 `--task-allow-plan-scan` 授权。
- `threads` 为 1..6。计划最多 100000 行、16 MiB；读取分页 limit 为 1..100，单次序列化结果至多 1 MiB。
- 起止时间均包含，解析后的秒值写入计划。此计划的纯日期 `end` 为当日 00:00，不是单会话历史 `until` 的日末语义。

审阅只允许把 `export` 改为 `""`、`"0"` 或 `"1"`，拒绝重复或未知身份，不修改统计和时间。每次审阅返回新的不可变引用，原版本不变，也不意味着内容已获人工批准。黑名单模式排除 `0`；白名单模式只取 `1`，全空标记在白名单下是空选集，不自动扩大范围。

执行重新核对选集摘要，使用原始聊天 JSON 导出，写入新的任务目录，不增量合并旧目录；dry-run 不创建聊天文件。计划统计使用已保存材料构建私有数据库快照，不信任旧明文缓存，也不获取新密钥。体积估计中 SQLite TEXT `length` 是字符计数，不等于磁盘字节；必须同时阅读行状态和来源完整性，不能只看零计数。

## 产物登记与读取

产物接口覆盖 `export_all` 聊天目录、`export_history` 单会话历史、`export_voices` 原始语音及证据组，以及计划相关产物，不承诺所有 CLI 导出形式都接入同一接口。worker 在聊天文件发布后登记产物，再继续后续处理；登记清单不是任意文件目录。

CLI 通过 `wx tasks artifacts`、`wx tasks read-artifact` 查询和分块读取，计划预览使用 `wx tasks read-plan`。MCP 宿主需明确启用 `--tasks --task-allow-artifact-read`，才开放产物清单与读取；提交某类任务的授权不能替代读取授权，反之亦然。审阅和执行计划还要求相应任务类型授权。请求不能指定账号、宿主输出根或任意文件路径。

只允许读取终态任务的已登记产物。清单每页最多 100 项，服务字节块至多 1 MiB；MCP 会按帧预算进一步收紧。返回 Base64 字节、偏移、EOF、大小和 SHA-256。接收方应逐块推进并核对总长度及完整摘要，不拼接不同摘要的内容，也不把可重复的显示名当作产物 ID。

读取时通过同一受保护句柄检查文件身份、内容摘要和字节；替换、改写、删除或重解析路径会被拒绝。Web 以附件下载交付，用户 HTML 不在工作台同源内联执行。下载票据绑定运行实例、账号、任务、产物和 60 秒有效期，仅用于对应下载；到期前可能重用，不承诺一次性消费。

## 原始语音任务与读写授权

`export_voices` 不转码、不转写、不下载远端媒体。它复用语音选择与严格关联，但只向全新任务根发布。SILK与证据两个文件均完成校验后作为一个组登记；不完整组不计 `exported`，也不能通过产物接口读取。分页、None/0、媒体与消息时间的区别见[语音契约](../wechat/voice.md)。

MCP宿主提交该任务需显式允许任务类型及媒体写入；读取产物另需 `--task-allow-artifact-read`，两种权限不相互授予。示例使用合成会话：

```powershell
wx mcp --tasks --task-kind export_voices --task-allow-media-write --task-allow-artifact-read
```

Web新建原始语音任务需在本地启动时使用 `wx web --task-allow-media-write`，默认关闭。HTTP布尔值、请求Options或共享设置RPC不能开启该权限。该开关限定新原始语音任务，不是所有任务或读取接口的全局开关。

写入开关关闭时，同幂等键且完整规范化参数一致的已接受任务只能经Get恢复，不再次Submit；参数不同返回409，新请求或已淘汰记录拒绝且不入队。省略limit与显式null可对应同一默认值，0则是不同请求。已有任务不会因开关关闭或Web退出自动取消。

Web读取使用固定账号、token认证及单产物下载票据，独立于写入开关；它没有照搬MCP的启动参数作为读取授权。MCP断连不取消已接受任务；响应丢失用原幂等键恢复，显式取消保留已登记前缀。进程重启仍按interrupted处理，不自动续跑。

产物数量、索引、哈希和读取预算可能使任务失败或不完整；没有业务条数上限不等于无限资源。任务不覆盖已有输出目录，同步CLI的overwrite能力仍是独立边界，不能据此宣称所有媒体入口完全对等。

## 取消、失败与保留

文件落盘、登记完成、读取可用和整项业务成功是不同状态。强杀发生在发布与登记之间时，文件可能存在但不可通过产物接口读取；不会扫描并收编孤立文件。失败或取消不撤回先前已登记产物，也不保证整批事务。

计划执行报告 `finalized=false` 时，初始 `selected_count=0` 不证明选集为空，`failed_count=0` 不证明没有失败；必须结合任务状态、终结标记与诊断。收尾受取消、超时、索引装载和系统 I/O 约束，不承诺硬实时中断。

意外退出后未完成任务记为 `interrupted`，不自动续跑。任务记录淘汰不删除磁盘产物，也不保证接口在记录淘汰后仍可读取；清理由独立授权流程执行。当前完整性边界与进程归属见[架构](architecture.md)。
