# 范围、术语与证据

已知目标：Windows 微信 4.1.13.65。源码项目面向 Windows x64 MSVC；平台支持与格式适配是两个不同结论。没有验证过的微信版本、macOS、手机端不纳入本说明。

本仓库记录三种内容：微信文件或记录的格式、wx-workbench 对这些格式的适配行为，以及可用于其他项目的设计建议。后两种不能自动当作微信内部实现事实。

## 证据等级

| 标记 | 含义 | 不能推出 |
|---|---|---|
| C：代码可证实 | 已阅读指定源码，能确认当前实现执行的操作 | 微信所有版本都如此、算法在实机始终成功 |
| T：合成验证 | 人工构造输入的检查或可复现向量 | 对真实账号的覆盖率、服务器行为 |
| O：实验观察 | 明确版本和条件下的独立实机观察 | 未测设备/版本/账号的普遍行为 |
| U：待验证 | 有待进一步取证的问题 | 不得作为已实现事实 |

首版主要为 C；附带 T 的检查必须注明实际执行与否。本轮不访问私人数据库，因此没有新增 O 级实机证据。来源文档的历史观察只作为线索，不能升级为本轮实验。

## 术语

- 账号根：某一账号的本地目录，含 `db_storage`，不等同于产品运行目录。
- 数据库分片：例如 `message/message_0.db`；编号不推导消息或语音的归属。
- 消息身份：账号上下文 + 会话标识 + 完整来源分片 + 消息本地 ID；必要时加时间、服务端 ID复核。
- 恢复：解密或去混淆得到原始媒体字节；不是视频帧解码或语音识别。
- 发布：在本地处理流程中表示把验证通过的临时结果原子替换到目标路径；与 GitHub 公开发布不同。
- 主库快照：仅数据库主文件的某个状态；没有合并 WAL 时不声称包含最新已提交记录。

安全材料不等同于普通元数据。数据库密钥、图片材料、表情材料、SNS token/密钥字段应由调用方提供并限制生命周期，不写入公开例子。所有示例账号及内容均为人工构造。
